 # Ignotus releases
 
## Релизы

## 0.2.0 — 29/09/2026
Крупное обновление. У Игнотуса появился локальный агент: он готовит документы Word и Excel и точно считает по таблицам, не показывая модели реальные данные — подстановка происходит на вашем компьютере. Ещё в этой версии: генерация изображений, настраиваемый системный промт и журнал обезличивания с выгрузкой для проверяющих.
- Агент: создаёт документы Word и таблицы Excel, точно считает агрегаты по табличным данным
- Генерация изображений: модели OpenAI GPT Image 2.5 и Google Nano Banana
- Системный промт в настройках: ваши инструкции отдельно от служебных
- Журнал обезличивания по сессиям + выгрузка архивом (CSV и JSON) за выбранный период
- Проверка на остаточные данные теперь использует сам движок и видит все типы
- Новые модели: GPT-6 Astra, Gemini 3.8 Flash, обновлённый список DeepSeek
  
### 0.1.2 — 08.09.2026

- Новый тип данных — БИК
- Плашка автообновления с прогрессом
