 # Ignotus releases
 
## Релизы

### 0.1.3 — 21.09.2026
Теперь поведение ассистента можно настроить под себя. В настройках появился
системный промт: отдельно ваши инструкции и защищённая часть про обезличивание.
- Системный промт в настройках
- Автоподстановка модели, провайдера и даты в промт
- Счётчик знаков и токенов

### 0.1.2 — 08.09.2026
Движок обезличивания стал точнее и распознаёт больше данных. Обновления
скачиваются с наглядным прогрессом.
- Новый тип данных — БИК
- Плашка автообновления с прогрессом

### 0.1.1 — 31.08.2026
Стабилизирующий релиз: исправления после первых запусков на Windows.
- Исправлена работа с кириллицей на Windows
